SCENTORA storefront - current frontend prototype

Contents:
- scentora_mobile_store_demo.html

How to preview:
1. Open the HTML file in a mobile or desktop browser.
2. Product photos are embedded in the HTML, so no separate image folder is required.

Important:
- This is a frontend prototype, not a production full-stack store.
- Orders are currently stored in the browser's localStorage on the same device.
- The admin panel is a demo and is NOT protected by real server-side authentication.
- Before accepting real customer orders, replace localStorage with a secure backend/database,
  implement proper admin authentication and authorization, and review privacy/security.
- Product prices and descriptions should be verified before launch.
